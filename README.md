# AI-Based Loan Prediction System

## Overview
This project is an AI-powered loan approval prediction system developed using Machine Learning techniques. The system predicts whether a loan application is likely to be approved based on applicant information such as income, education, employment status, credit history, and loan amount.

The project demonstrates an end-to-end supervised machine learning workflow including:
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model training
- Model evaluation
- Prediction system
